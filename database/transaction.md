# Transaction

## 한 줄 정의

트랜잭션은 여러 데이터베이스 작업을 하나의 논리적인 작업 단위로 묶은 것입니다.

## 왜 필요한가

중간에 실패했을 때 데이터가 어중간한 상태로 남으면 안 되기 때문입니다.

예를 들어 계좌 이체는 두 작업이 함께 성공해야 합니다.

```text
A 계좌에서 10,000원 차감
B 계좌에 10,000원 추가
```

첫 번째만 성공하고 두 번째가 실패하면 데이터가 깨집니다. 그래서 두 작업을 하나의 트랜잭션으로 묶습니다.

## ACID

- Atomicity: 모두 성공하거나 모두 실패해야 합니다.
- Consistency: 작업 후에도 데이터 규칙이 깨지면 안 됩니다.
- Isolation: 동시에 실행되는 트랜잭션끼리 서로 방해하면 안 됩니다.
- Durability: 성공한 결과는 저장되어야 합니다.

## 내 프로젝트와 연결

현재 `multichat-java`에는 데이터베이스가 없습니다. 하지만 채팅 로그를 DB에 저장하는 기능을 추가한다면 트랜잭션을 고려할 수 있습니다.

예를 들어 메시지를 저장하고, 읽지 않은 메시지 수를 업데이트하는 작업은 함께 성공해야 할 수 있습니다.

```text
messages 테이블에 채팅 저장
unread_count 업데이트
```

## 30초 면접 답변

트랜잭션은 여러 데이터베이스 작업을 하나의 작업 단위로 묶는 것입니다. 중간에 실패했을 때 일부만 반영되면 데이터 정합성이 깨질 수 있기 때문에 필요합니다. 대표 성질은 ACID이고, 예를 들어 계좌 이체처럼 출금과 입금이 함께 성공하거나 함께 실패해야 하는 상황에서 중요합니다.
