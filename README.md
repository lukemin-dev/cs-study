# CS Study

정보처리기사, 개발 면접, 개인 프로젝트 설명을 함께 준비하기 위한 CS 공부 저장소입니다.

이 저장소의 목표는 개념을 많이 외우는 것이 아니라, 면접에서 아래 흐름으로 설명할 수 있게 만드는 것입니다.

```text
개념 정의
-> 왜 필요한지
-> 간단한 예시
-> 내 프로젝트와 연결
-> 30초 면접 답변
```

## 폴더 구조

```text
cs-study/
  network/            네트워크
  operating-system/   운영체제
  database/           데이터베이스
  java/               Java 기본기
  data-structure/     자료구조
  algorithm/          알고리즘
  software-engineering/ 설계와 운영 감각
  interview/          면접 답변 정리
  templates/          새 문서 작성 템플릿
```

## 공부 규칙

- 한 문서에 한 개념만 정리합니다.
- 정의만 쓰지 말고 "왜 필요한지"를 꼭 씁니다.
- 가능하면 내 프로젝트와 연결합니다.
- 마지막에는 30초 면접 답변을 적습니다.
- 이해가 안 된 부분은 `TODO`로 남기고 나중에 다시 봅니다.
