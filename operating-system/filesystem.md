# File System

## 한 줄 정의

파일시스템은 운영체제가 파일과 폴더를 저장하고 찾고 이동할 수 있게 관리하는 구조입니다.

## 왜 필요한가

프로그램은 로그, 설정 파일, 입력 데이터, 결과 파일을 자주 다룹니다. 파일 경로, 권한, 중복 이름, 이동 실패 같은 문제를 고려해야 안정적으로 동작합니다.

## 내 프로젝트와 연결

`file-organizer-agent`는 파일시스템을 직접 다룹니다.

```text
Path.iterdir()     폴더 안 파일 목록 조회
Path.is_file()     파일인지 확인
mkdir()            카테고리 폴더 생성
shutil.move()      파일 이동
```

또한 숨김 파일은 제외하고, 같은 이름의 파일이 이미 있으면 `_1`, `_2`를 붙여 충돌을 피합니다.

`seo-automation-system`도 JSON 입력 파일을 읽고 Markdown 리포트 파일을 생성하므로 파일 I/O와 연결됩니다.

## 30초 면접 답변

파일시스템은 운영체제가 파일과 폴더를 관리하는 구조입니다. 파일을 다루는 프로그램에서는 경로, 권한, 중복 이름, 이동 실패를 고려해야 합니다. 제 `file-organizer-agent` 프로젝트에서는 `Path.iterdir()`로 대상 폴더를 순회하고, 확장자별 카테고리 폴더를 만든 뒤 `shutil.move()`로 파일을 이동했습니다. 실제 이동 전에는 dry-run으로 계획을 먼저 보여줘 안전성을 높였습니다.
